# 純前端圖片保護加強版（不切圖）

本版本仍只有 HTML、CSS、JavaScript，沒有後端。

## 已加入
- 不再在 `main.js` 直接以明文列出完整圖片路徑。
- 圖片檔名改為亂數名稱。
- 路徑表以 Base64 包裝，執行時才還原。
- 首頁只保留目前作品、上一張、下一張的 `src`。
- 其他作品會移除 `src`，避免一進站就把全部作品載入。
- 禁止圖片右鍵選單。
- 禁止圖片拖曳。
- `robots.txt` 要求搜尋引擎不要索引 images。
- HTML 加入 `noimageindex`。

## 本版刻意沒有使用
- 圖片切片
- 4×4 圖磚
- Canvas 拼圖

因此每幅作品仍維持「一個完整圖片檔」，後續新增與管理較簡單。

## 重要限制
只要瀏覽器能顯示圖片，使用者仍可從 Network、瀏覽器快取、
自動化瀏覽器等方式取得檔案。本版本只能提高簡單爬蟲與一般下載的門檻，
不能取代 Django / ASP.NET Core 的 Token、Session、Rate Limit 等後端防護。
